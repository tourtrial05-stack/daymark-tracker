# Daymark Daily Productivity Tracker

## Publish with GitHub Pages

1. Sign in to GitHub as `harsh05baghel-coder`.
2. Create a **Public** repository named `daymark-tracker`.
3. Upload `index.html` and this `README.md` to the repository's root (top-level) folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to finish publishing. The intended URL is:
   `https://harsh05baghel-coder.github.io/daymark-tracker/`

The URL will work after the repository is created and Pages is enabled; it is not live before then.

## Important data note

The tracker saves information in the current browser using local storage. It does not automatically sync data across different browsers or devices. Use the tracker’s export/backup feature periodically, and import the backup if moving to another browser or device.
